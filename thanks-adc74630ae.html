Your first five minutes

  • Home shows today, reminders and unfinished tasks. Tap Clear examples when you are ready to start fresh.
  • Calendar holds events and birthdays. Tap an event to add notes and a checklist.
  • Diary is for daily writing with a mood and tags. You can lock it with a PIN in Settings.
  • Daily notes are for quick to-dos and sketches.
  • Recipes save from a TikTok link, a recipe website, pasted text or a screenshot.

Alerts when the app is closed

Sereluniva can't send notifications by itself. To get alerts, tap the calendar icon on an event. It sends the event to your phone's calendar app, which rings the reminder.

Recipe import

Recipes import from TikTok links, recipe websites, pasted text and screenshots. Instagram and Facebook posts can't be imported, because those apps block outside access.

Your data and backups

  • Everything you write stays on your own device. We never see it.
  • Clearing your browser data or deleting the app can erase it.
  • Go to Settings, then Save backup file now and then, and keep the file somewhere private. Backup files are not encrypted.
  • To move to a new phone, save a backup on the old one, install Sereluniva on the new one, then use Restore from backup.
  • The diary PIN is a screen lock, not encryption. Write down your recovery code when you set the PIN, because we can't recover it.
